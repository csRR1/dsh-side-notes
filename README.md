# dsh-side-notes（旁注）

DSH 旁注插件：主 agent 干活时，不打断地收集你的想法 —— 问题走旁路回答，需求攒到停顿点批量投递，紧急才插话。

## 功能

- **旁注收件箱**：composer 便签按钮 / `Alt+Enter` / 右侧栏「旁注」tab。
- **停顿点自动投递**：agent 一轮结束且主输入框空闲时，10 秒倒计时（可「立即/取消」），≤3 条合并成一条 steer。
- **助手消息批注**：定稿助手消息右上角 ✎，批注带消息锚点，5 秒内可撤回。
- **项目备忘**：左栏底部「项目备忘」按钮，按工作区跨会话保存；支持勾完成、最近删除、图片（IndexedDB，**双击放大**）。
- **旁问档 1**：本地规则回答「做到哪了 / 下一步 / 卡在哪」，**0 token**。
- **旁问档 3**：要查代码的问题，自动开一个独立子会话去查，结果一键「插回主线」。

## 安装

1. 让 agent 执行：`plugin_manager install_bundle target=<本目录绝对路径>`
2. 重启 DSH，刷新页面。
3. 控制台出现 `[side-notes] L6 apply ok` 即成功。

## 四个坑

1. **目录不能删/挪**（本地安装是 link，删目录即失效）。
2. **安装会弹权限请求**，要点同意。
3. **替换已安装包需重启 DSH**。
4. **版本不对会白屏** → 插件自带自检提示。

## 已知限制

- 数据仅 localStorage / IndexedDB 级持久，清浏览器数据即丢。
- 档 3 会在左侧栏新建旁问工作区/会话，暂不支持自动清理。
- 无 i18n（硬编码中文）。
